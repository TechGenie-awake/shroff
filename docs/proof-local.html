Honest by design. The 8,000-MSME training set is synthetic — it encodes known MSME risk economics (cash-flow buffers, bounce history, GST punctuality, GST-vs-bank divergence, buyer concentration, headcount) and draws the default label from those same economics plus irreducible noise, so the metrics above demonstrate the pipeline — feature engine, monotone constraints, calibration, scorecard, decisioning — not production performance. Isotonic calibration is fit on the reporting holdout (a build-window compromise; AUC/KS unaffected, Brier optimistic). In production the model is retrained and recalibrated on IDBI's own portfolio outcomes through the bank's model-risk process. The negative-registry data is genuinely real government data, captured once and loaded offline; two registries (MCA disqualified directors, IBBI CIRP) remain honestly-labelled samples because their bulk feeds are access-gated — data IDBI already holds internally.
