# DATA.md — synthetic MSME dataset (datagen v1, seed=42)

Generated by `uv run python -m datagen.generate` from `ml/`. Fully deterministic:
`numpy default_rng(42)`, `random.seed(42)`, `Faker.seed(42)`, `uuid5` on a fixed namespace,
and per-firm sub-streams seeded via `zlib.crc32` (NOT Python `hash()`, which is process-salted).
Verified byte-identical SHA-256 across consecutive runs.

## Generative assumptions

**Archetypes** (population share): kirana/retail 30%, trader 22%, light manufacturer 18%,
services 18%, seasonal agri-adjacent 12%. Each sets base monthly inflow (log-uniform,
₹1.8L–₹60L depending on archetype), UPI inflow share (kirana high ~0.55–0.85, manufacturer
low ~0.05–0.25), B2B share, buyer concentration, headcount range, UPI ticket size,
seasonality amplitude (agri 0.35–0.60 sinusoid, others 0.03–0.18), and a **benign
cash-divergence band** (kirana/agri legitimately declare more GST turnover than lands in the
bank — deliberate noise so divergence is not a perfect fraud tell).

**Entities/IDs**: 75% proprietorship / 25% pvt_ltd. PAN format-valid (5L+4D+1L; 4th char
P=proprietorship, C=company). GSTIN chars 3–12 embed the PAN; state codes 27/07/29/33/09/24/36.
CIN only for pvt_ltd (`U#####<ST><year>PTC######`). UDYAM per state. **Checksums are NOT
enforced anywhere — structure-only validity, by contract.**

**Latent quality** `q ~ N(0,1)` per firm drives (with idiosyncratic noise on every mapping,
so no single field is deterministic in q): inflow trend (≈0.4%/mo ± 0.7%·q), operating margin,
balance buffer ratio (median ≈0.29 of monthly outflow), bounce Poisson rate, GST punctuality
probability, probability of GST-turnover inflation (weak firms declare +15–52% above bank
inflows), nil-return probability, buyer concentration, headcount trend, self-transfer share.

## Label: `default_12m`

Latent health index computed from **realized** firm-level aggregates (not from q), z-scored
across the 8,000-firm population, weighted:

| Signal (24-mo aggregate) | Weight (＋ = riskier) |
|---|---|
| Inflow growth: log(mean last-6m / first-6m) | −0.90 |
| Balance buffer: mean EOD avg balance / mean outflow | −0.70 |
| Bounce rate (bounces/month) | +0.85 |
| GST divergence: \|log(Σ declared / Σ bank inflow)\| | +0.75 |
| GST on-time filing share | −0.60 |
| Days-near-zero (mean/month) | +0.50 |
| Self-transfer share of inflows (round-tripping) | +0.45 |
| Headcount trend (last-6m vs first-6m) | −0.40 |
| Top-3 buyer concentration (mean) | +0.35 |

`latent = 1.9·z(risk) + N(0, 1.15) + c` → `p = sigmoid(latent)` → `default_12m ~ Bernoulli(p)`,
with intercept `c` bisected to hit prevalence 0.10.

**Measured on this build (seed 42):** prevalence **0.1024**; oracle AUC (noiseless index vs
sampled labels) **0.859**; achievable AUC (numpy logistic regression on the 9 firm-level
signals, 70/30 test split) **0.882**. The injected noise is real: a trained model should land
~0.85–0.92, and anything reporting ≈1.0 is leaking the label.

## Honesty note

This is **synthetic data encoding known MSME risk economics** (cash-flow buffers, bounce
history, GST punctuality, GST-vs-bank divergence, buyer concentration, headcount trend —
signals documented in HKMA/ASTRI BIS Papers 148, AI-BAAM, and the GST/AA literature). The
label is generated from those same economics plus irreducible noise, so model metrics on this
data demonstrate the *pipeline*, not production performance. **In production the model must be
retrained and recalibrated on IDBI's own MSME portfolio outcomes** through the bank's model
risk-management process; the synthetic AUC is a ceiling-shaped rehearsal, not a claim.
